## E-commerce Analytics Pipeline (End-to-End)
🧠 Overview

This project builds a full end-to-end data pipeline for an e-commerce system, covering:

Multi-source data ingestion (Shopify, Sapo POS, Payment Gateways)
Data transformation using Python ETL
Data warehousing in BigQuery
Business intelligence dashboards using Power BI

👉 The goal is to provide actionable insights on customer behavior, financial performance, and payment risk
